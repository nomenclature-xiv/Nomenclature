# Nomenclature
[![Discord](https://img.shields.io/discord/1444069861889151091?label=Discord)](https://discord.gg/RycGZWr8AZ)

A plugin to let you edit your name and world displays however your heart desires, synced with friends or with everyone in its own syncing service! We offer both XIVAuth and Lodestone for authentication.

The full link to the repository file is:
```
https://raw.githubusercontent.com/nomenclature-xiv/Nomenclature/main/repo.json
```
## IMPORTANT:
This plugin is not compatible with any other plugins that modify nameplates, including but not limited to Character Select and Glance. If you would like to use Nomenclature, please turn any nameplate-modifying features off before installing.

This only applies to text modifications. Other modifications should be compatible.
